FehmiCorp S3 Object Storage

Local Executable & Endpoint Configuration Reference

1. Overview

The local binary server.exe located at C:\Program Files\Fehmi\S3\server.exe runs an optimized HTTP server exposing S3-compatible endpoints and asset indexing utilities.

Installation Directory: C:\Program Files\Fehmi\S3\

2. Running server.exe

Open PowerShell as Administrator to start the local S3 instance:

& "C:\Program Files\Fehmi\S3\server.exe" server `
  --address "127.0.0.1:9000" `
  --data-dir "D:\Fehmi\S3\storage"

3. Server Route Reference

The Go HTTP multiplexer registers the following operation paths:

HTTP Method Route Path Pattern Description
POST /sign Generate presigned upload/download URLs
GET /find Search indexed assets and metadata
GET /list List all created buckets
PUT /create/{bucket} Create a new storage bucket
HEAD /fetch/{bucket} Check bucket existence and headers
DELETE /delete/{bucket} Delete an empty bucket
GET /objs/{bucket} List objects inside a bucket
PUT /obj/{bucket}/{key...} Upload or overwrite an object
GET /obj/{bucket}/{key...} Download object contents
HEAD /obj/{bucket}/{key...} Retrieve object metadata without body
DELETE /obj/{bucket}/{key...} Delete a specific object

4. Multipart Upload Routes

Optimized for large files and desktop/mobile agent synchronization:

HTTP Method Route Path Pattern Description
POST /begin/{bucket}/{key...} Start the uploading content
PUT /part/{bucket}/{key...} Uploading the content into chunks
POST /done/{bucket}/{key...} After complete the uploading verify the chunks to consolidate the file
DELETE /end/{bucket}/{key...} Abort the uploading and delete the uploaded chunks
